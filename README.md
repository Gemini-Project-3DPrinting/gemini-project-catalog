# Gemini Project Catalog

Каталог: https://gemini-project-3dprinting.github.io/gemini-project-catalog/

9 карточек и 31 фотография из Telegram-канала @geminiproject_3dprinting. Изображения хранятся в assets/works, товары — в products.json. Для обновления добавьте фото и измените products.json; GitHub Pages публикует ветку main из корня. Публикация без сборки, оплаты, регистрации и базы данных.

NFC-визитка находится в другом репозитории contact и этим проектом не изменяется.
